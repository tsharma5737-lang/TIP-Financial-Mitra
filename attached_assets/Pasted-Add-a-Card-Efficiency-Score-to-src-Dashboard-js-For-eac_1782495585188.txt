Add a Card Efficiency Score to src/Dashboard.js. For each card, calculate a score out of 100 using this logic:

1. Fee Value Score (25 points):
- If annual fee is 0: full 25 points
- If annual fee > 0: calculate (total benefits extracted / annual fee paid) ratio
- Benefits extracted = (currentSpend x average cashback rate for top 2 categories) + lounge value (domestic lounges x 500 + international lounges x 1500) + milestone rewards already unlocked
- Score = min(25, ratio x 25)

2. Spend Alignment Score (25 points):
- Check if currentSpend pattern matches the card's best categories
- If currentSpend > 50% of annualFeeWaiverSpend: 25 points
- If currentSpend > 25%: 15 points  
- If currentSpend < 25%: 5 points
- If no annual fee waiver: 20 points base

3. Milestone Health Score (25 points):
- If all milestones unlocked: 25 points
- If on track (currentSpend / annualFeeWaiverSpend > 0.6): 20 points
- If behind (currentSpend / annualFeeWaiverSpend > 0.3): 12 points
- If very behind or no milestones: 5 points

4. Rewards Efficiency Score (25 points):
- Based on rewardPointValue: 
- 1.00 per point = 25 points
- 0.50 per point = 18 points
- 0.30 per point = 12 points
- 0.25 per point = 8 points
- 0.20 per point = 5 points

Final score = sum of all 4 components, rounded to nearest whole number
